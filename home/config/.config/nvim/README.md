# Neovim 操作手册

本手册只记需要记忆的操作。`<Space>` 是 Leader 键；按 `<Space>?` 可查看当前配置的快捷键提示。
下文未特别注明时，按键均在普通模式使用；编辑结束按 `Esc` 回到普通模式。

## 按相对行号移动

左侧行号显示的是相对当前光标的距离：

| 操作 | 按键 |
| --- | --- |
| 向下 8 行 / 向上 3 行 | `8j` / `3k` |
| 向下 / 向上半屏 | `Ctrl+d` / `Ctrl+u` |
| 将当前行移到屏幕中央 | `zz` |
| 跳回上一个位置 / 再向前 | `Ctrl+o` / `Ctrl+i` |

跳到明确的行号可输入 `:42` 回车，定位到第 42 行。

## 按数量复制、删除和修改

数字放在操作前，表示重复多少次；`yy` 是复制行，`dd` 是删除行，`cc` 是修改整行：

| 目标 | 操作 |
| --- | --- |
| 从当前行起复制 5 行 | `5yy` |
| 从当前行起删除 3 行 | `3dd` |
| 从当前行起修改 2 行 | `2cc` |
| 复制当前行及下方 5 行（共 6 行） | `y5j` |
| 删除当前行及上方 4 行（共 5 行） | `d4k` |

`y`、`d`、`c` 可以和移动组合：例如 `yw` 复制到下一个单词边界，`d$` 删除到行尾，`c}` 修改到下一段落。`"+` 指定系统剪贴板，例如 `"+5yy` 复制 5 行到系统剪贴板；`"+p` 从系统剪贴板粘贴。

## 修改单词或括号内容

`i` 表示只操作内部，`a` 表示连外围符号一起操作；与 `c`（修改）、`d`（删除）、`y`（复制）组合：

| 操作 | 示例 |
| --- | --- |
| 修改光标所在单词 | `ciw` |
| 删除光标所在单词 | `diw` |
| 复制光标所在单词 | `yiw` |
| 修改引号内部 / 连引号一起修改 | `ci"` / `ca"` |
| 删除括号内部 / 连括号一起删除 | `di(` / `da(` |

## 搜索与跳转

| 操作 | 按键 |
| --- | --- |
| 向前搜索文字 | `/文字`，回车 |
| 跳到下一个 / 上一个匹配 | `n` / `N` |
| 搜索光标所在单词 | `*`；`n`、`N` 继续跳转 |
| 跳到定义 / 声明 | `gd` / `gD` |
| 查看光标处文档 | `K` |
| 返回跳转前的位置 | `Ctrl+o` |

搜索高亮可用 `:nohlsearch` 清除。

## 当前配置的常用功能

| 按键 | 功能 |
| --- | --- |
| `Ctrl+p` | 查找文件 |
| `<Space>fg` / `<Space>fw` | 搜索项目内容 / 搜索光标下单词 |
| `<Space>fb` / `<Space>fr` | 查找已打开的缓冲区 / 最近文件 |
| `<Space>rn` / `<Space>ca` | 重命名符号 / 代码操作 |
| `[d` / `]d` | 上一个 / 下一个诊断 |
| `<Space>cf` | 格式化当前文件 |
| `<Space>tt` / `<Space>tv` | 在下方 / 右侧打开内置终端 |
| `Ctrl+h/j/k/l` | 切换到左 / 下 / 上 / 右分屏 |
| `]b` / `[b` | 下一个 / 上一个缓冲区 |

代码补全菜单中用 `Ctrl+n` / `Ctrl+p` 选择下一项 / 上一项，`Enter` 确认，`Ctrl+e` 关闭菜单。格式化不会自动触发，需手动按 `<Space>cf`。

## 配置与帮助

- 按 `<Space>l` 打开插件管理面板；`:Lazy restore` 按锁定文件恢复插件版本。
- `:checkhealth` 检查 Neovim 环境；`:checkhealth vim.lsp` 检查语言服务。
- 保存用 `:w` 或 `<Space>w`；关闭当前窗口用 `<Space>q`，退出 Neovim 用 `<Space>Q`。
